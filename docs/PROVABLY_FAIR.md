# 🎲 Provably Fair Algorithm Specification (SHA-256 HMAC)

This document describes the cryptographic foundation and mathematical derivation used in the Aviator Crash Game to guarantee 100% fair and tamper-proof round outcomes.

---

## 📐 1. Mathematical Formulation

The crash multiplier for each round is calculated deterministically *before* the round begins using the **HMAC-SHA256** hashing standard.

### Inputs:
1. **Server Seed ($S$):** A 64-character cryptographically secure hexadecimal string generated by the server.
2. **Client Seed ($C$):** A public entropy string chosen by the platform or verified by players.
3. **Nonce ($N$):** The sequential round number (e.g. `1001`, `1002`, ...).

### Algorithm Steps:

1. **HMAC Hash Generation:**
   $$\text{Hash} = \text{HMAC-SHA256}(S, C + ":" + N)$$

2. **52-Bit Slice:**
   Extract the first 13 hexadecimal characters (52 bits) of the hash:
   $$h = \text{hexToDecimal}(\text{Hash}[0 \dots 12])$$
   $$e = 2^{52} = 4,503,599,627,370,496$$

3. **House Edge & Instant Crash Distribution:**
   With platform House Edge $E = 3.0\%$ ($97.0\%$ RTP):
   $$\text{If } h \pmod{\text{round}(100 / E)} = 0 \implies \text{Multiplier} = 1.00\text{x}$$
   $$\text{Otherwise: } \text{Multiplier} = \max\left(1.00, \left\lfloor \frac{100 \times e - h \times E}{e - h} \right\rfloor / 100\right)$$

## 🔍 2. Independent Verification Code

### JavaScript / Node.js
```javascript
const crypto = require('crypto');

function calculateCrashMultiplier(serverSeed, clientSeed, nonce, houseEdge = 3.0) {
  const hash = crypto
    .createHmac('sha256', serverSeed)
    .update(`${clientSeed}:${nonce}`)
    .digest('hex');

  const hexSub = hash.substring(0, 13);
  const h = parseInt(hexSub, 16);
  const e = Math.pow(2, 52);

  const houseInterval = Math.round(100 / houseEdge);
  if (h % houseInterval === 0) {
    return 1.00;
  }

  const rawVal = Math.floor((100 * e - h * houseEdge) / (e - h)) / 100;
  return Math.max(1.00, Number(rawVal.toFixed(2)));
}

// Example:
const serverSeed = "8cf5e640438f2e2e6b7ab4da1d980c42a56a13a7aeaf272f977ba9bee532be30";
const clientSeed = "c1f7281ab0982341";
const nonce = 1025;

console.log("Calculated Crash Multiplier:", calculateCrashMultiplier(serverSeed, clientSeed, nonce));
```

### Python 3
```python
import hmac
import hashlib

def calculate_crash_multiplier(server_seed: str, client_seed: str, nonce: int, house_edge: float = 3.0) -> float:
    message = f"{client_seed}:{nonce}".encode('utf-8')
    key = server_seed.encode('utf-8')
    
    hash_hex = hmac.new(key, message, hashlib.sha256).hexdigest()
    hex_sub = hash_hex[:13]
    h = int(hex_sub, 16)
    e = 2 ** 52
    
    house_interval = round(100 / house_edge)
    if h % house_interval == 0:
        return 1.00
        
    raw_val = int((100 * e - h * house_edge) / (e - h)) / 100.0
    return max(1.00, round(raw_val, 2))

# Test
print(calculate_crash_multiplier(
    "8cf5e640438f2e2e6b7ab4da1d980c42a56a13a7aeaf272f977ba9bee532be30",
    "c1f7281ab0982341",
    1025
))
```
